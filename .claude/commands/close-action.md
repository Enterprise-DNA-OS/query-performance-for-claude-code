# Close Action

Read the relevant query, source or action first. Use actual identities, dates and evidence, never the placeholders below. Run `npm run performance -- close-action --ref="<action ID>" --evidence="<actual evidence reference>" --actor="<reviewer>"`. Missing required context must come from the operator. Drafts stay private in drafts/. Never send, execute query text, apply tuning changes or certify compliance. For a weekly review, read slow-queries, regression-review and attention before producing the draft. Confirm the resulting records or file in this conversation.
