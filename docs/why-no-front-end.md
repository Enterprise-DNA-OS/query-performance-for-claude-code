# Why no front end

The weekly review needs saved measurements, accountable follow-up and readable evidence. Ask the coding agent to run the command and show the answer. Read-only HTML reports carry your brand without a running web server.

A live monitoring screen provides continuously refreshed charts, drill-down explain plans, alerts and correlation with application traces. This base provides none of those. It reviews saved exported windows. A desktop export and a later review do not provide incident detection, mobile push notifications or offline field capture.

Enterprise DNA can scope collection, connections and screens for a custom version. Keep the operational monitor until those requirements are met. The free base stays a database and command library.
